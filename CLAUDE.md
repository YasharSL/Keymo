# Keymo

Windows tray app for controlling the mouse cursor from the keyboard (C# / .NET 10 / WinForms).

Before and after any code change, use the `ystack-code` skill. Rules live in `coding-guide/`.

- Check everything: `./check.ps1` (fast: `./check.ps1 -Fast`)
- Run: `dotnet run --project src/Keymo`
